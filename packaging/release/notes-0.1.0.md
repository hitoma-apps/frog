# FROG 0.1.0

The first release of FROG (Fast Read-Oriented Gmail): a small, fast Gmail client built for reading.

## Downloads

- **Linux (x86_64):** `frog.AppImage`. This is the version that updates itself: when a newer release is out, FROG offers to install it.
- **macOS (universal, Apple Silicon and Intel):** `FROG-macos-universal.zip`. Not yet signed with a Developer ID, so macOS will block it the first time. See the README for how to open it.
- **Windows (x86_64):** `frog.exe`. Not yet code-signed, so Windows may warn, and Smart App Control may block it. Automatic updates on Windows wait for signing.

## Notes

- Your mail stays on Gmail. FROG keeps a local cache, which you can clear or limit in Settings → Cache.
- Settings and saved sign-ins are kept across updates.
