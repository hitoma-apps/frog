# FROG 0.1.2

## Changes

- Right-click a message's title to search for all mail from its sender. The search runs in the message list, the search results and the waiting view.

## Downloads

- **Linux (x86_64):** `frog.AppImage`. Installed copies of 0.1.0 and 0.1.1 update themselves to this version.
- **macOS (universal):** `FROG-macos-universal.zip`. Not yet signed with a Developer ID.
- **Windows (x86_64):** `frog.exe`. Not yet code-signed. Automatic updates on Windows wait for signing.
