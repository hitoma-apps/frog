# FROG 0.1.10

## Changes

- The mail cache opens in the background, so the window appears straight away.
- While the cache opens, a panel shows what's happening. After a few seconds it names antivirus scanning, such as Windows Defender, as a likely cause of a slow start.
- Choosing a label to add works from the list: the list stays open while you use it, and it closes after you pick a label.

## Downloads

- **Linux (x86_64):** `frog.AppImage`. Installed copies of 0.1.0 and later update themselves to this version.
- **macOS (universal):** `FROG-macos-universal.zip`. Not yet signed with a Developer ID, so macOS asks you to approve it on first open. Move the app to Applications first.
- **Windows (x86_64):** `frog.exe`. Not yet code-signed. Automatic updates on Windows wait for signing.
